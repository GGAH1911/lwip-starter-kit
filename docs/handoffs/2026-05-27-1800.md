## Decisions & rationale

- **Did NOT strip the example content / handoffs.** Two clean models existed:
  (A) ship as a reference instance with the example documented, (B) strip to a
  pristine blank template + mark as a GitHub template repo. Chose A: the
  comparison mesh is genuinely useful as a "what a populated LWIP looks like"
  demo, and stripping is destructive. The README callout makes the kit-vs-
  example split explicit, so newcomers aren't confused. B remains available if
  the user later wants a one-click "Use this template" blank start.
- **MIT, not Apache/GPL.** Lowest-friction, matches the two sibling projects in
  this space, appropriate for a small protocol kit.
- **Description de-hyped.** Consistent with the user's standing preference; the
  technical term "zero-entropy" stays (it's LWIP's actual vocabulary), the
  marketing "self-healing AI knowledge networks" went.
