## Decisions & rationale

- **Soft alert.** Keeps with v1.3's "don't over-block" philosophy. A hard
  dangling rule would punish the normal forward-link workflow. One-line change
  to promote it to hard later if a project wants strictness.
- **Wikilinks only.** Markdown links are explicit paths; checking them produces
  false positives on directory/anchor/external targets. Wikilinks are the
  semantic mesh references that *should* resolve.
- **`kind` field on edges.** Needed to distinguish wikilink vs mdlink for the
  dangling check, and useful metadata for downstream tooling anyway.
- **No version bump.** This is a new *soft* tooling check under v1.6, not a
  change to the four Zero-Entropy rules or the tier model.

## Open questions / deferred

  nodes — but log.md, index.md, and hub prose are scanned for edges. Options
