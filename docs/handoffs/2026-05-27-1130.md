## Decisions & rationale

- **edges.jsonl is a derived cache, not source of truth.** Gitignored under `docs/.lwip/`. Reasoning: markdown stays the only canonical form; the JSONL is a tooling convenience. If a user hand-edited edges.jsonl it would silently diverge from markdown — that's why it's gitignored and regenerated on every audit.
- **`addresses_gap` added to meaningful link types instead of as a separate category.** Promotes "this resolves a tracked unknown" to first-class semantic content, and lets the orphan check naturally treat a resolved gap as semantically anchored.
- **Foundations/ and gaps/ as conventions, not tier exemptions.** They follow the same Tier 2 Zero-Entropy rules. Calling them "Tier 2 conventions" rather than separate tiers keeps the rule set simple. The distinction is semantic (what the folder *means*), not structural (what rules apply).
- **Prune Protocol split into stale vs failed.** OmegaWiki's "anti-repetition memory" insight — failed paths are signal, not noise. Burying them in `archive/` without a semantic edge loses the warning. Mandating a hub→archive `contradicts` edge keeps the dead end discoverable.
- **`LWIP_Specification.md` still untouched** despite being v1.2. Now contradicts v1.6 in three more places (mention of "JIT scripts at every shutdown" — outdated since v1.3; no Tier 0/2.5/conventions; no edges.jsonl). Still flagged for follow-up.
- **OmegaWiki ideas NOT adopted**: the 26 slash commands, 9 fixed entity types, MCP cross-model review server, GitHub Actions daily-arxiv cron, web UI visualisation. All of these would convert LWIP from "protocol" to "domain platform" — different category. The 4 absorbed ideas (foundations, gaps, anti-repetition, edges.jsonl) preserve LWIP's universalism while filling structural gaps.
